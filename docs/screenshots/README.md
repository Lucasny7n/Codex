# Screenshots

Temporary visual validation screenshots are not versioned. Use:

```bash
npm run screenshots
```

Playwright writes to `test-results/screenshots/` by default. That folder is ignored.

Intentional README/release screenshots live in:

```text
docs/assets/screenshots/
```

Promote only stable, reviewed assets with these names:

- `ailu-home.png`
- `ailu-ai-workspace.png`
- `ailu-llm-library.png`
- `ailu-responsive.png`
