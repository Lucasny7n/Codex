# Modelo de Entrega Final

Use este modelo sempre que entregar um app, ferramenta, script ou automação.

## 1. O que foi implementado
- Resultado funcional.
- Escopo entregue.
- Limites conhecidos.

## 2. Como usar
- Fluxo principal.
- Exemplo prático.
- Entradas esperadas.

## 3. Como abrir
- Comando de desenvolvimento.
- Comando de build ou pacote, se existir.

## 4. Como testar
- Teste manual mínimo.
- Comandos de validação.
- Resultado esperado.

## 5. Como reverter
- Backups gerados.
- Script ou comando de rollback.
- Arquivos que devem ser restaurados.

## 6. O que exige cuidado
- Ações destrutivas ou privilegiadas.
- Mudanças em boot, kernel, serviços, pacotes ou arquivos críticos.
- Qualquer etapa que precise de aprovação explícita.

## 7. O que depende de instalação
- Pacotes necessários.
- Helper, policy, serviço ou configuração externa.
- O que ainda não foi aplicado no sistema.

## 8. Arquivos principais
- Arquivos criados.
- Arquivos alterados.
- Papel de cada arquivo.

## 9. Problemas conhecidos
- Limitações atuais.
- Falhas não resolvidas.
- Workarounds disponíveis.

## 10. Próximos passos
- Melhorias recomendadas.
- Validação adicional.
- Decisões pendentes do usuário.
