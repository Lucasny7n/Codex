# Code of Conduct

## Our Standard

Ailu AI Studio welcomes focused, respectful technical collaboration. Keep discussion concrete, reproducible and useful for maintainers and users.

Examples of expected behavior:

- Report issues with steps, environment and validation evidence.
- Redact secrets, private files and credentials.
- Challenge technical decisions with clear reasoning.
- Keep feedback about code and product behavior, not people.

Examples of unacceptable behavior:

- Harassment, insults, discriminatory language or personal attacks.
- Posting API keys, private logs or exploit details publicly.
- Pressuring maintainers to claim unvalidated functionality as ready.
- Repeated off-topic or hostile comments.

## Enforcement

Maintainers may edit, hide or remove comments and issues that violate this standard. Serious or repeated violations can lead to a temporary or permanent ban from project spaces.

## Reporting

Report conduct or security concerns to the maintainer with context, links and redacted evidence.
